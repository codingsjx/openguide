# AI 指南超时设置（2026-10-23）

在贡献指南生成按钮旁新增“超时设置”，支持 10–120 秒整数和 25/45/60/90/120 秒快捷选项，默认 25 秒。设置保存在当前浏览器，仅下一次 AI 生成生效；打开设置、取消修改或保存设置都不会自动重新生成，当前请求继续使用开始时的值。

后端 `/api/guide` 接收 `model_timeout_s`，校验范围后传给模型客户端。每阶段仍不重试。前端整次等待上限为 `max(180, 4 × 秒数 + 80)` 秒，规则模式仍使用 180 秒；弹窗展示该上限。取消等待入口保留。生成结果中的 `model_timeout_s` 记录本次实际选用值，规则模式为空，旧指南不补造历史设置。

这里的模型超时是 HTTP 客户端的网络等待设置，不是模型总生成耗时保证；提高值不能保证服务成功返回。本轮没有重新调用外部模型，也不声称超时成功率改善。

验证：

- API 回归覆盖默认值、10/60/120 秒实际传给模型客户端、输出记录、非法/超范围参数在联网前被拒绝、规则模式不创建模型客户端。
- 前端覆盖请求体中的设置值、120 秒时页面计时上限同步为 560 秒、偏好保存与存储不可用、已保存指南兼容与参数校验。
- 浏览器实际选择 60 秒并保存，按钮显示 60 秒；改为 75 秒后取消，重新打开仍是 60 秒。截图为保存后的设置面板，未重新生成旁边的旧指南。
- 本地运行 API schema 确认默认 25、最小 10、最大 120；发送 121 得到 422。
- 后端与 benchmark 282 项通过（1 条依赖弃用警告）；前端 33 项通过，lint 与生产构建通过。生产包体积提示仍存在。

本轮是 AI 代理开发与验收，不是真人试用或独立人工复核。
