# 仓库工作台顶部动效（2026-10-23）

读取仓库后，原页面收起首页介绍，仅显示简短标题。本轮改为紧凑的动态概览，沿用用户指定的青绿色、橙色和浅灰底；同时保留前一轮删除重复顶部导航的修改。

## 行为

- 读取概况时显示真实的读取状态。完成后按取得的数据展示仓库名称、默认分支、主要语言和 README 入口；采集缺失时不把旧语言或文档信号伪装成已取得。
- 交互示例、离线指南和在线概况分别标注。离线记录不继承前一个仓库的画像；示例不显示模拟画像为实时结果。
- 右侧加入资料节点轻微浮动、连接光带、轨道和脉冲，贡献路径明确为示意，不展示虚构的步骤完成百分比。
- 显示当前查看的功能页；“查看贡献指南”可切回真实指南标签并滚动到工作区。
- 有暂停/播放按钮；尊重系统减少动画偏好。动效使用 CSS，没有额外轮询、资料请求或模型调用。

## 验证

- 前端 36 项测试通过，lint、类型检查、生产构建通过；生产包体积提示仍存在。新增覆盖读取中、查询参数不泄漏、示例/离线跨仓库隔离和部分采集状态。
- 浏览器实测 CSS 动画状态为 running，点击暂停后为 paused，恢复后为 running；切换问答后顶部显示“当前查看 · 贡献问答”，点击顶部指南入口后指南标签的 aria-selected 为 true。
- 先查看 Requests 静态示例，再通过文件选择器载入上一轮 OpenGuide 的实际指南，顶部正确显示 codingsjx/openguide、引用版本 8c21e6d43798 和离线状态，没有混入示例语言等信息。
- 桌面 DOM 内容/视口宽度均为 1281 CSS px，窄屏均为 372 CSS px，无整页横向溢出；测试后恢复默认尺寸。
- desktop.png / mobile.png 是上述离线回放的实际画面；动画需在网页中观看，截图只记录布局。
