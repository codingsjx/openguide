# 新手流程复查：贡献准备保存与快照重连

本轮从现有页面检查模式选择、学习记录、选题到草稿、刷新恢复和解释帮助。保持项目方向，未修改后端或模型配置。

## 原有数据保护

原窗口已有使用者记录。本轮使用独立页面验收副本：基于此前公开规则指南，为各步骤标题添加明确的“独立页面验收”前缀，避免与使用者原指南的进度标识混用。原窗口的完成状态没有修改；用户原指南备份仅留在 Git 忽略的本机运行目录，没有纳入公开验收文件。验收结束后关闭副本窗口，并将首页的继续入口恢复到原窗口的指南。

## 本次发现并修复

### 1. 未形成改动时，选题无法单独保存

旧工作台允许 C 到 D 保留表单，但只能在实际修改及文件路径齐备后生成 PR 草稿。只有任务及问题描述时，页面要求离开前导出草稿，却没有可用的准备记录导出入口。`before-incomplete-task.txt` 保留原状态。

新增“导出准备记录 JSON”和“从准备记录恢复”：

- 支持未完成的任务、修改说明和验证记录；不因此绕过 PR 草稿条件。
- 文件仅下载到本机，不自动保存贡献表单，也不发送给模型或 GitHub。文件含用户填写的 diff 和测试输出。
- JSON 格式独立于指南文件，按 UTF-8 字节限制为 2 MB，按表单字段限制长度，忽略未声明字段，拒绝无效结构或测试状态。
- 只允许当前仓库恢复；文件参考版本不同则明确提示，并将原参考版本保留在后续准备文件及草稿中。
- 文件读取后先显示任务、版本、测试状态，使用者明确选择后才替换表单。失败、未运行和不一致的验证记录保持原样，不自动改成通过。

实测填写的是明确标为“页面模拟”的任务，没有实际改动、运行命令或社区贡献。实际下载的 `preparation-demo.json` 刷新后可恢复；读取预览时表单仍为空，确认后恢复任务及问题，PR 草稿仍禁用。其他仓库文件被拒绝，当前任务保持原样。旧参考版本预览给出提示，取消不会覆盖表单。

### 2. 快照恢复后，启用在线功能的入口不直接

快照只显示本机资料，问答和体检禁用，原先需要用户自行回到仓库输入重新提交。

新增“重新联网读取，启用问答与体检”，按快速规则路径读取，不触发模型生成；同时提供先保存指南的入口，并提示新步骤不会自动继承旧进度。实际重连成功后，两个标签恢复可用，指南明确显示规则模式，见 `reconnected-tabs.txt`。

使用明确标为纯 UI 模拟的不存在仓库，触发实际 GitHub 404。请求失败后，本机指南和填写中的模拟任务均保留，见 `failed-reconnect-retains-form.txt`。该夹具没有仓库事实或执行命令，不作为真实仓库效果样本。

### 3. 切换指南后残留旧的联网错误

失败分支测试后导入另一个指南，发现页首仍显示上一次不存在仓库的错误，容易与当前仓库混淆。已在成功导入指南及切换静态示例时清理旧读取错误，并在导入指南时清理旧画像。

重新导入验收副本后，旧错误不再显示，见 `source-switch-clears-error.txt`。历史错误现场见 `stale-error-before-source-switch.txt`。

## 仍建议优先优化

1. **聚焦当前命令的通俗解释**：本轮实际请求后端安装步骤的“看不懂为什么”，返回 backend/README.md 原文及 benchmark/README.md 来源；没有直接解释 uv sync 的作用及适用条件。见 `why-help-sample.txt`。下一轮可先改善相关资料筛选，再区分仓库专属理由与工具的一般解释，保留出处和资料不足提示。
2. **逐步结果记录更结构化**：学习摘要仍是自由文本，尚未逐步采集实际目录、退出码、失败用例和验证范围。可帮助复盘，但不能把手动标记当作执行证明。
3. **跨仓库与真实新手效果**：本轮测试的是交互和数据恢复，没有新增真人试用、命令执行或模型质量对照；这些效果仍需单独验证。

## 验证范围

- 新增准备文件往返、仓库隔离、格式与边界、失败结果保留、版本差异及序列化字节限制回归。
- 前端单元检查、类型构建和 lint 的最终结果见 `validation.json`；后端未修改，本轮没有重新计入历史后端测试。
- 下载验收工具曾中断一次，恢复连接后重新确认页面与实际下载文件，未将工具中断计为应用崩溃。
- 全部公开任务、表单及失败数据为明确标记的 UI 模拟；没有执行指南命令、创建上游 Issue/PR，或将模拟标记计作用户效果。
