# 报名字段工作稿

作品名称：OpenGuide开源贡献向导

申报方向：保持现有方向一“开源赋能的 AI 应用创新”。如需变更申报分类，先由团队确认。

作品简介：

面向首次参与开源贡献的学生，OpenGuide从GitHub仓库文档、构建配置和任务信息中检索依据，生成环境搭建、测试、选题及PR准备的分阶段指南。系统区分来源存在、引用匹配和命令原文匹配，隐藏未通过核验的命令，并支持追问、来源定位与指南离线回放。项目已进行自动化测试、真实模型探索性实验和指定环境命令实跑，公开代码、评测脚本和统计记录；实跑包含失败，真人效果、独立人工复核及贡献闭环待完成，不将路径命中率作为事实正确率。

提交前：团队复核原创与授权、人工标注、实验记录、实际视频及最终PDF。当前文案如实披露未完成项，不代表最终效果验收通过。
