# 现场演示脚本（固定证据主线，3–5 分钟）

当前有真实模型输出和固定环境执行记录，尚无独立用户实验与已核验的上游贡献闭环。演示应明确区分实时生成、规则生成与保存的历史输出，不保证缓存后模型响应秒级或不会限流。

## 启动

后端按 README 启动；前端 `pnpm dev`，默认端口 5173。本机当前验收实例在 5179。先检查 `/health` 和页面能否打开；不在录制画面中展示真实 API Key。

## 主线

1. 说明具体任务：新手需要找到克隆、安装、测试与贡献入口，资料散落在不同文件。
2. 点“导入已保存指南”，选择 `output/guides/requests-20261018.json`。明确这是固定 SHA 的历史模型输出与当前后处理结果，不是现场重新分析。
3. 展示克隆先于安装、测试的顺序，查看 Makefile 推导的工作目录、输入路径与前置步骤。说明目录推导仍需结合实际调用方式核对。
4. 打开固定提交的 Makefile 行号，区分来源存在、原文匹配、历史执行结果。不要声称所有自然语言建议都已证明正确。
5. 展示开发依赖安装通过与完整 CI 失败的不同记录。完整 CI 为 625 passed、6 failed；数据结构子集通过不能代替全量结果。链接修复后的证书单例复测也不能代替全量重跑。
6. 展示评测控制：统一全局索引与四视角路由在相同条件下比较；参考集标记 AI 源码复核、独立人工复核待完成。结果只作探索性展示。
7. 收尾说明开放代码、验证计划和可复用脚本；真实新手实验和上游贡献仍待补齐。

## 在线可选段

网络与服务允许时，再输入真实仓库并生成。超时、抓取缺失或模型回退都如实展示，不将保存的输出伪装成实时结果。保存指南模式不提供联网追问；只有实时分析模式演示追问。

Click 的安装信息部分指向外部 Pallets 文档，不能预先承诺全部上手步骤齐全或存在可直接认领的 issue。Mocha 可作跨语言生成案例，但没有完成所有平台的运行验证。

## 时间分配

问题 30 秒，固定指南与操作上下文 90 秒，原文与执行记录 60 秒，评测方法和边界 45 秒，开放成果及下一步 15 秒。在线生成可单独录制并说明实际等待时间，不强行塞进固定时长。
