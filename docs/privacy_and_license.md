# 隐私、数据流与部署边界

核对日期：2026-10-24。以下描述当前实现，不替代参赛团队对服务条款、授权和公开范围的实际审核。

## 1. 联网与发送范围

| 功能 | 接收方 | 实际发送内容与边界 |
|---|---|---|
| 仓库画像、指南和追问的资料采集 | GitHub API / 固定版本原文下载端点 | 仓库名称、文件路径、提交版本与查询参数；即使关闭 AI，在线分析仍会访问 GitHub |
| AI 指南 | 用户配置的模型服务 | 阶段提示、已取得的公开仓库片段及输出格式要求 |
| AI 问答 | 用户配置的模型服务 | 当前问题、用于理解追问的有限先前问题，以及检索片段；问题不一定只是仓库原文 |
| 报错定位 | 用户配置的模型服务（满足调用条件时） | 当前步骤、命令、用户粘贴日志的有界片段及仓库上下文；日志可能含个人信息，发送前须自行脱敏 |
| “这步太粗”“看不懂为什么” | GitHub；本地规则处理 | 当前实现不为这两项调用模型；通用命令解释与仓库原文分开展示 |
| 离线导入指南 | 本浏览器 | 不因导入重新采集资料或调用模型；主动重新联网时恢复在线数据流 |

API 密钥通过请求认证头发送给用户选定的模型端点，这是调用所必需的认证，不进入模型提示。后端收到的模型密钥及日志不可视为系统自动完成脱敏。仓库公开可访问不等同于可任意再分发，引用归原作者所有。

项目没有用户账号、追踪埋点或独立遥测模块；后端与反向代理可能有请求访问日志，宿主服务、GitHub 和模型提供方也有各自的数据处理规则。本项目无法保证第三方不记录或保留请求。

## 2. 保存位置与生命周期

| 位置 | 内容 | 生命周期与移除方式 |
|---|---|---|
| 后端 `.cache/` | GitHub 响应与原文缓存 | 默认 3600 秒有效；过期项在读取时删除，不是定时清扫。停止服务后可由部署者删除缓存目录 |
| `.chroma/`（可选） | 本地索引 | 启用可选向量依赖时可能持久化，由部署者管理 |
| 后端进程内存 | 按页面令牌隔离的模型配置 | 闲置超过 30 分钟后下次访问失效并清理；最多 128 个会话，超过上限淘汰较旧项；重启清空 |
| 本地 `backend/.env` 或部署环境变量 | 部署者提供的默认配置与密钥 | 文件或环境由部署者自行管理；`.gitignore` 不等于加密，不会因为页面会话结束自动删除 |
| 浏览器 localStorage | 指南快照、按指南身份保存的学习进度、执行摘要、等待设置等 | 刷新后保留；可在浏览器站点存储设置中清除。不是账号云同步或加密存储 |
| 当前页面内存 | 问答、诊断原始日志、贡献准备表单、待审阅草稿、页面令牌 | 刷新或离开页面会丢失；原始诊断日志不进入学习记录，切换步骤清空 |
| 用户主动下载的文件 | 指南 JSON、学习/问答 Markdown、准备记录与 PR 草稿 | 由用户自行保存与删除，可能包含个人摘要、路径、diff 或日志摘录；分享前自行检查 |

浏览器页面令牌只用于区分内存配置，不包含模型密钥，也不写入 localStorage。页面不读取已有密钥回显；提交成功后清空密钥输入框。刷新会生成新令牌，旧配置不会迁移到新页面。若部署者配置了服务端 `.env` 默认模型，页面仍可使用该默认值；个人覆盖与服务端默认值分开。

## 3. 默认部署范围

默认 Compose 端口绑定 `127.0.0.1`，面向本机演示。页面配置隔离不等于用户认证、授权、限流或计费配额。需要多人公网使用时，部署者仍须在可信反向代理或网关增加访问控制、TLS、请求/费用限制、网络出口策略和日志治理，再明确允许哪些数据提交到模型端点。不要将开发服务直接当作公开生产服务。

GitHub 凭据由部署者按最小必要权限配置；本项目只读公开仓库，不要求为运行授予仓库写入权限。默认不执行生成的命令、不自动认领任务或提交 PR。

## 4. 开放与授权

本仓库自主实现部分按 MIT 发布，依赖、嵌入模型和商业服务遵循各自条款，见 [第三方资源说明](third_party_disclosure.md)。默认确定性检索不下载嵌入模型；启用可选向量依赖时可能需要首次下载，但嵌入计算在本地进行。

评测中的原始提示、响应和第三方资料全文默认留在 Git 忽略目录；公开统计与必要出处不能证明已取得任意再分发授权。团队应检查公开内容及 AI 辅助产物来源与权利边界，见 [AI 辅助开发说明](ai_assistance_disclosure.md)。

## 5. 尚需团队完成的审核

- 确认实际模型服务的条款、授权与数据处理方式，不能把连通性测试当作授权审核。
- 审查提交报告、视频和开放文件中的个人信息、密钥、学校/导师信息及第三方受限内容。
- 核对许可证、依赖实际版本、自主开发边界与团队共同授权。
- 如启用公网访问，完成上述访问控制及配额配置并取得部署验收记录。
