# 演示视频脚本（3–5 分钟）

**用途**：录制提交用的作品演示视频。
**配套**：现场演示流程见 [`demo_script.md`](demo_script.md)；本文件是**分镜脚本**。
**总时长**：约 4 分 30 秒（可压缩到 3 分钟，见 §压缩建议）。

**录制前必做**：按 `demo_script.md` §0 的预热清单，把三个仓库各跑一遍，
让 GitHub 响应缓存与索引落盘——录制时是秒级响应，且不会中途触发限流。

## 压缩到 3 分钟的剪法

若时长受限，按此顺序删减：

1. **删** 0:15–0:35 的痛点截图段，并入开场（省 20s）
2. **删** 3:05–3:20 的第二个仓库（省 15s）——改为一句话带过"管线不绑定语言"
3. **压** 3:20–3:50 的架构段到 15s（省 15s）
4. **压** 1:20–1:40 的体检卡到 10s（省 10s）

**不要删**：证据跳转（2:10–2:30）与评测段（3:50–4:15）——这两段是"可验证"的证明。

## 录制清单

**设备与环境**

- [ ] 屏幕录制 1920×1080，浏览器 100% 缩放（避免模糊）
- [ ] 关闭无关通知、书签栏、其他标签页
- [ ] 后端 `/health` 正常；三个仓库已预热
- [ ] 若走 AI 生成：LLM Key 已配好并**试跑过一次**（确认能出结果再录）

**画面**

- [ ] 鼠标移动放慢，点击前停顿半秒
- [ ] 命令块、证据标签等关键信息给足停留时间（≥2 秒）
- [ ] 跳转 GitHub 的瞬间不要剪掉（这是可信度来源）

**音频**

- [ ] 旁白语速 ≈ 每分钟 220 字
- [ ] 关键句（"无证据不宣称"、"不是模型编的"）放慢并加重

**合规**

- [ ] 视频中**不得出现任何真实 API Key**（录制前检查设置弹窗）
- [ ] 若展示评测数字，注明"人工复核过的 golden 仓库集"
