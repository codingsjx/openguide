# 贡献问答完善（2026-10-22）

原入口只调用 `/api/search`，展示最多五条、每条截断到 320 字符的检索片段。本轮保留兼容检索接口，新增 `/api/ask` 和问答页面，将回答、原文、缺口及后续动作放在同一流程中，项目方向不变。

## 功能

- 提供中文解释，每个 AI 要点引用具体来源。可点击固定提交的文件及行号，展开服务端实际返回的完整片段。优先展开回答首先引用的来源，不再仅显示文件名。
- 原文片段按实际文件补齐附近行和段落，避免停在半个词或半句话；片段最长 2400 字符，查看全文件仍需打开原始出处。行号根据实际文档计算，兼容 CRLF 换行。
- 安装/测试命令由已有规则与证据审计独立提取、匹配原文；AI 正文不负责发明命令。展示执行位置及其推导依据，明确尚未执行。
- 同一仓库可继续追问。前端发送最近四个已完成的问题，服务端最多接收六个，每个最多 2000 字符；问答首轮取得固定文件提交，后续沿用该版本。历史问题用于理解代词，不作为事实来源，服务器只从当前仓库取得证据。
- 明确切换话题时采用新话题；“这条命令在哪个目录执行”承接前面的安装/测试问题，不误路由成文件架构问题。
- 资料不足、仅有文件树、具体 issue 未采集或 GitHub 抓取失败时，保留缺口、人工核对入口和下一步，不伪造答案。文件树只证明路径存在；普通开放 issue 只是浏览样本，不能保证适合新手或可认领。
- 可以选择 AI 整理或仅原文、取消等待、开始新对话、重试失败的问题及下载 Markdown 问答记录。切换仓库清空历史与提交信息，并中止本页等待，忽略迟到响应。当前页刷新后不会恢复历史。

## 核验边界

AI 输出只接受已提供的来源 ID 和能在来源中匹配的引文，匹配允许空白/软换行差异，不替换词语。成对的行内格式符号可以去掉，内容仍须经过校验，代码块和未匹配格式仍被拦截。对常见新命令语法、可识别文件路径、原文没有的数字、执行成功断言及 issue 可认领保证做保守拒绝。中文紧贴命令或文件路径的边界也有回归覆盖。提示中的合成示例仅说明格式，其来源 ID 不在当前仓库引用表中，不能作为事实出处。

这不等于验证了每个中文解释的语义蕴含关系，也不能保证所有错误说法都被过滤。页面明确标为 AI 解读，并要求结合原文上下文判断；人工复核仍待完成。

模型不可用、超时或解读未通过核验时保留原文整理，标明方式及安全的原因代码，不把回退冒充 AI 成功。模型单次超时设为 40 秒、不重试；页面等待有取消入口。问题和检索片段可能交给当前配置的服务，页面在发送前提醒移除密钥和个人信息。服务端不保存会话，前端不将完整模型回答重新作为事实发送。
