# 分阶段回退与规则路线补全（2026-10-21）

## 实现

在线产品逐阶段生成：某阶段模型不可用或输出无有效步骤时，仅替换该阶段，保留此前成功输出并继续后续阶段。`stage_modes` 记录 A-D 的生成来源；全规则为 heuristic，部分成功为 mixed，全模型为 llm。命令展开等确定性处理仍可将总体模式标为 mixed，生成来源不代表语义正确或命令已运行。

严格模型实验仍在失败时抛错，禁止规则回退。既有受控实验不重新计分；本轮不能用于声称新策略的真实模型成功率。

规则环境阶段分别寻找克隆、隔离环境和安装命令，找不到对应信息则待确认；开发用途需结合完整原文核对。测试阶段过滤 tox 等配置模板，不把 `{posargs:tests}` 当作可直接运行命令；发布用途的 `.publishenv` 不作为开发环境推荐。PR 阶段提取实际贡献文档中的 Fork/分支、测试、PR 与审查要求，保留引用，不生成通用 git 提交流程。资料缺失时保留可见的待确认入口；没有完成操作的含义。

核验可能将误放在 D 的克隆移到 A，再去重；在线产品会为因此缺失的阶段补回规则入口。严格实验不作此规则补齐，保留缺失以便如实评价模型输出。
