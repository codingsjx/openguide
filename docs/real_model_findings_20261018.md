# 真实模型探索性实验与当前结论

日期：2026-10-18。保持开源项目新手贡献向导的原方向；未改变申报主方向。

## 实际完成

- 对 Click、Requests、Cookiecutter、Mocha、Camelot 五个仓库进行探索性真实模型实验。
- 共 7 个仓库轮次、28 个成功实验组；63 次成功模型调用，服务报告合计 299110 tokens。另有最初接口/非配对试跑，不混入上述统计。
- 每轮包含单次生成、普通 RAG、四视角生成、对同一四视角输出进行证据审计。审计组不另行调用模型。
- Click 有两次重复；Requests 包括检索优化前后各一次。因此不能将 7 个轮次当成 7 个独立仓库，也不能将不同代码版本合并成最终准确率。
- 请求模型 `gpt-5.5`，由团队提供的兼容服务承载。模型身份与 token 用量仅依据服务返回，未独立核验权重身份。
- GitHub API 限流导致一次扩展抓取中断，后续三个仓库改为 Git 源码快照。Git 快照没有抓取 issue、stars、语言统计和 release 活跃度，这些字段属于未测，不代表不存在。

结构化统计位于 `benchmark/reports/real_model_exploration_20261018.json`。原始来源文本、提示和响应归档仅保存在本地 `benchmark/reports/controlled_*/`，已从 Git 与分发包排除；不默认公开第三方来源全文。

## 得到的工程发现

1. 来源路径存在不能证明命令或引文受到支持。修复路径、行号、原文核验和回填后，未核验命令会被隐藏。
2. 原检索被通用英文词干扰，Requests 的测试阶段曾优先命中关闭 issue 的自动化。新增停用词过滤、测试工具查询词、阶段命令优先和来源去重后，同一快照能优先检索到 Makefile 与 tox.ini。
3. Click 的部分开发流程依赖外部 Pallets 文档。当前只分析仓库资料，仍存在安装与贡献步骤缺口，不能用泛化教程伪装仓库专属说明。
4. 四视角方案尚未证明全面优于普通 RAG；必须扩大、复核数据再决定各阶段采用何种路由策略。
5. 严格命令匹配会拒绝未声明的等价写法，且旧 golden 已存在版本漂移。当前指标是诊断信号，不能直接当作语义正确率或竞赛最终效果。
