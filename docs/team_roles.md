## 协作总则

1. **每周末集成验收**：M0-M4 每个里程碑以"可演示集成"为准，不是某人的模块写完。
2. **先对齐接口再并行**：画像 schema、检索接口、生成 schema 是全局约定，A 定稿后 B/C 才能并行，避免返工。
3. **红线**：Key 只进本地 `.env`，不进任何可分享文件；无证据不宣称；评测数字只报人工复核过的仓库集。
4. **信息同步**：每周集成碰一次（周日）。git 按功能分支开发，M 结束合并 main 并代码评审。
